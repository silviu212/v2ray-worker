2. Instalează

iPhone
  1. Setări → Celular → Adaugă eSIM.
  2. Alege „Folosește codul QR” și scanează.
  3. Denumește linia (ex. „Europa”) și setează-o pentru date celulare.
  4. Activează „Roaming de date” pentru linia eSIM.
Android (Samsung, Pixel etc.)
  1. Setări → Conexiuni / Rețea și internet → Manager SIM.
  2. Adaugă eSIM → Scanează codul QR.
  3. Setează eSIM-ul ca SIM pentru date mobile.
  4. Activează „Roaming” pentru eSIM.
